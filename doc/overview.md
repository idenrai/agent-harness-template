# Template Overview

This template provides a standardized AI pair programming harness.
Recently, we have added capabilities for tracking Architecture Decision Records (ADR), managing database migrations, and performing strict security reviews during the PR/Review process.

이 템플릿은 표준화된 AI 페어 프로그래밍 하네스를 제공합니다.
최근 아키텍처 의사결정 기록(ADR) 추적, 데이터베이스 마이그레이션 관리, 그리고 PR/리뷰 과정에서의 엄격한 보안 감사 기능이 추가되었습니다.
