# Template Overview

This template provides a standardized AI pair programming harness.
Recently, we have added capabilities for tracking Architecture Decision Records (ADR), managing database migrations, strict security reviews during the PR/Review process, production Prompt Engineering workflows (/prompt) for structured LLM application development, full-scale project refactoring workflows (/refactor) with Martin Fowler refactoring patterns and clean architecture standards, and an elevated frontend design & UI/UX engineering system featuring taste-driven anti-slop guidelines (design-taste-frontend) and comprehensive multi-stack UI/UX intelligence (ui-ux-pro-max).

이 템플릿은 표준화된 AI 페어 프로그래밍 하네스를 제공합니다.
최근 아키텍처 의사결정 기록(ADR) 추적, 데이터베이스 마이그레이션 관리, PR/리뷰 과정에서의 엄격한 보안 감사 기능, 구조화된 LLM 애플리케이션 개발을 위한 프롬프트 엔지니어링 워크플로우(/prompt), 마틴 파울러 리팩토링 패턴 및 클린 아키텍처 기반의 프로젝트 전면 리팩토링 워크플로우(/refactor), 그리고 템플릿화된 디자인 탈피를 위한 테이스트 기반 프론트엔드 디자인 지침(design-taste-frontend)과 다중 스택 UI/UX 인텔리전스(ui-ux-pro-max)를 아우르는 고도화된 UI/UX 설계 체계가 추가되었습니다.
