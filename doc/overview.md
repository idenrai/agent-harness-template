# Template Overview

This template provides a standardized AI pair programming harness.
Recently, we have added capabilities for tracking Architecture Decision Records (ADR), managing database migrations, strict security reviews during the PR/Review process, and production Prompt Engineering workflows (/prompt) for structured LLM application development.

이 템플릿은 표준화된 AI 페어 프로그래밍 하네스를 제공합니다.
최근 아키텍처 의사결정 기록(ADR) 추적, 데이터베이스 마이그레이션 관리, PR/리뷰 과정에서의 엄격한 보안 감사 기능, 그리고 구조화된 LLM 애플리케이션 개발을 위한 프롬프트 엔지니어링 워크플로우(/prompt)가 추가되었습니다.
